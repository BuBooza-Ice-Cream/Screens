# BuBooza Smithfield screens

In-store menu screens, shown on the TVs through Fugo (Web Page app).

| TV | Link |
|---|---|
| Left – Screen 1 (flavours & prices) | `…/#menu-ice` |
| Middle – Screen 2 (meet the menu) | `…/#menu-more` |
| Right – Screen 3 (promos) | `…/#promo` |

To change text or prices, edit `index.html` (sections `t-menu-ice`, `t-menu-more`, `t-promo`) and commit. TVs pick it up within 30 minutes.
